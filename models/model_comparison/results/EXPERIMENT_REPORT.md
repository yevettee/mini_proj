# YOLO 모델 비교 실험 보고서

> YOLOv8, YOLO11, YOLO26 모델의 다양한 조건에서의 성능 비교

**실험 일자:** 2026-06-02  
**대상 클래스:** car, dummy (2 classes)

---

## 1. 실험 배경 및 목적

### 1.1 실험 배경

객체 탐지 모델 선택 시 단순히 벤치마크 성능만으로 판단하기 어렵습니다. 실제 배포 환경에서는 다음과 같은 요소들이 성능에 영향을 미칩니다:

- **입력 이미지 해상도**: 엣지 디바이스의 처리 능력 제한
- **이미지 품질 저하**: 카메라 초점 문제, 움직임 블러, 저조도 노이즈
- **실시간 처리 요구사항**: 추론 속도 vs 정확도 트레이드오프

### 1.2 실험 목적

1. **모델 아키텍처 비교**: YOLOv8, YOLO11, YOLO26의 기본 성능 차이 확인
2. **해상도 민감도 분석**: 저해상도에서의 성능 저하 정도 측정
3. **강건성 평가**: 이미지 품질 저하 상황에서의 모델 안정성 비교
4. **최적 모델 추천**: 상황별 최적의 모델 조합 제시

### 1.3 모델 특성

| 모델 | 버전 | 주요 특징 |
|------|------|----------|
| **YOLOv8** | 2023 | 안정적인 성능, 풍부한 생태계 |
| **YOLO11** | 2024 | 효율성 개선, 빠른 추론 속도 |
| **YOLO26** | 2025 | NMS-free 설계, 소형 객체 탐지 강점 |

## 2. 실험 설계

### 2.1 고정 변수 (Controlled Variables)

모든 실험에서 동일하게 적용된 설정:

| 변수 | 값 | 설명 |
|------|-----|------|
| `SEED` | 42 | 재현성을 위한 랜덤 시드 |
| `EPOCHS` | 100 | 최대 학습 에포크 |
| `PATIENCE` | 20 | Early stopping patience |
| `BATCH_SIZE` | 16 | 배치 크기 |
| `OPTIMIZER` | AdamW | Ultralytics 기본 옵티마이저 |
| `DATA_YAML` | ./data.yaml | 동일 데이터셋 사용 |

### 2.2 독립 변수 (Independent Variables)

| 변수 | 테스트 값 | 목적 |
|------|----------|------|
| **모델** | v8n, v11n, v26n, v8s, v11s, v26s | 아키텍처 비교 |
| **이미지 크기** | 320, 480, 640 | 해상도 영향 분석 |
| **Gaussian Blur** | σ=1.5 (약함), σ=2.5 (강함) | 초점/움직임 블러 시뮬레이션 |
| **Gaussian Noise** | var=0.02 | 저조도 환경 시뮬레이션 |
| **Augmentation** | Mosaic ON/OFF | 데이터 증강 효과 |

### 2.3 종속 변수 (Dependent Variables)

| 지표 | 설명 |
|------|------|
| **mAP50** | IoU 0.5에서의 평균 정밀도 |
| **mAP50-95** | IoU 0.5~0.95의 평균 정밀도 (COCO 표준) |
| **Precision** | 정밀도 (TP / (TP + FP)) |
| **Recall** | 재현율 (TP / (TP + FN)) |
| **F1 Score** | 정밀도와 재현율의 조화평균 |
| **Inference (ms)** | 단일 이미지 추론 시간 |
| **Train Time (min)** | 전체 학습 소요 시간 |

**분석:**
- 세 모델 모두 mAP50에서 우수한 성능 (0.993 이상)
- **mAP50-95**에서는 YOLO26n이 근소하게 앞섬 (0.842)
- **추론 속도**는 YOLO11n이 가장 빠름 (3.66ms)
- **Recall**에서 YOLOv8n, YOLO11n이 완벽한 1.0 달성

#### 3.3.2 Gaussian Noise (저조도 환경)

| 모델 | mAP50 | mAP50-95 | Precision | Recall | F1 Score |
|------|-------|----------|-----------|--------|----------|
| **YOLOv8n** | 0.995 | **0.845** | 0.997 | 1.000 | 0.998 |

| YOLO26n | 0.995 | 0.840 | 0.989 | 0.985 | 0.987 |

**분석:**
- 세 모델 모두 노이즈 환경에서 양호한 성능 유지
- **YOLOv8n**이 mAP50-95에서 가장 높음 (0.845)
- YOLO26n은 Recall이 약간 저하 (0.985)

#### 3.3.3 실제 강건성 테스트 (원본 학습 → Blur 추론)

> 위 3.3.1~3.3.2 실험은 **blur/noise 데이터로 학습 + 동일 조건 테스트**입니다.  
> 실제 배포 환경에서의 강건성을 측정하려면 **원본으로 학습한 모델이 blur 환경에서 얼마나 버티는지** 확인해야 합니다.

**테스트 조건:**
- 학습: 원본 이미지 (baseline 모델)
- 평가: Heavy Blur 테스트셋 (σ=2.5)

| 모델 | 원본 Test | Blur Test | mAP50-95 하락 | 하락률 |
|------|-----------|-----------|---------------|--------|
| **YOLOv8n** | 0.839 | 0.804 | -0.035 | **-4.2%** |
| YOLO11n | 0.836 | 0.768 | -0.068 | -8.1% |
| YOLO26n | 0.842 | 0.724 | -0.118 | -14.0% |

| 모델 | mAP50 | mAP50-95 | Precision | Recall |
|------|-------|----------|-----------|--------|
| **YOLOv8n** | 0.984 | **0.804** | 0.973 | **1.000** |
| YOLO11n | 0.985 | 0.768 | 0.964 | **1.000** |
| YOLO26n | 0.962 | 0.724 | 0.883 | 0.855 |

**핵심 발견:**
- **YOLOv8n이 실제 강건성에서 압도적 1위** (mAP50-95 하락 -4.2%)
- YOLO11n은 blur 학습 시 성능 좋았으나, 미경험 blur에는 -8.1% 하락
- **YOLO26n은 가장 취약** (-14.0% 하락, Recall도 0.855로 급락)
- YOLOv8n, YOLO11n은 Recall 1.0 유지 (객체 놓침 없음)

**기존 blur 실험과의 비교:**

| 조건 | v8n mAP50-95 | v11n mAP50-95 | v26n mAP50-95 |
|------|--------------|---------------|---------------|
| blur로 학습+평가 | 0.851 | 0.851 | 0.841 |
| **원본 학습 → blur 평가** | **0.804** | **0.768** | **0.724** |
| 차이 | -0.047 | -0.083 | -0.117 |

→ blur 데이터를 학습에 포함하면 성능이 크게 개선되지만, **사전에 blur를 예측할 수 없는 환경에서는 YOLOv8n이 가장 안전한 선택**입니다.

## 6. 결론

### 6.1 핵심 결론

1. **YOLO11n이 전반적으로 가장 균형 잡힌 선택**
   - 가장 빠른 추론 속도
   - blur 데이터로 학습 시 최고 성능
   - Augmentation 효과 극대화

2. **YOLOv8n은 실제 강건성의 왕**
   - **미경험 환경(blur)에서 성능 하락 최소** (-4.2% vs YOLO11n -8.1%, YOLO26n -14.0%)
   - 저해상도, 노이즈 환경에서 강점
   - Recall 1.0으로 놓침 최소화
   - **예측 불가능한 환경에 배포 시 최우선 선택**

3. **YOLO26n은 특정 조건에서 강점**
   - 중해상도(480px)에서 최고 mAP50-95
   - 소형 객체 탐지에 유리 (NMS-free 설계)
   - **단, 강건성 최하위** - 미경험 blur에서 mAP50-95 14% 하락, Recall 0.855로 급락

4. **Small 모델은 신중히 선택**
   - 현재 데이터셋에서는 Nano가 오히려 우수
   - YOLO26s만 모델 크기 증가가 효과적

### 6.2 최종 추천

| 우선순위 | 모델 | 조건 |
|----------|------|------|
| **1순위** | YOLO11n | 환경 예측 가능, 실시간 처리, 학습 데이터 통제 가능 |
| **2순위** | YOLOv8n | **환경 예측 불가**, 저해상도, 노이즈, 최고 강건성 필요 |
| **3순위** | YOLO26n (480px) | 정확도 최우선, 중해상도, 안정적 환경 |

> **핵심 인사이트**: 학습 때 본 적 없는 환경에서의 성능 저하를 최소화하려면 **YOLOv8n**이 가장 안전한 선택입니다.
